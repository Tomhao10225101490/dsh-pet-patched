# dsh-pet 🐾

一只住在 DeepSeek Harness 里的桌面宠物，一百余个透明动画，可多开、能上桌面。

安装与完整文档在仓库根 README：**<https://github.com/Tomhao10225101490/dsh-pet-patched>**

本目录已提交的 `lib/standalone.js` 可以直接 `node lib/standalone.js` 启动。不要先 `npm run build`，构建会用未打补丁的 `src/` 覆盖 `lib/`。
